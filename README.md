# Tasko

Single-user local-first task tracker. v1 in progress.

## Run instructions

> Full instructions will be documented in task-20. Quick start below.

```sh
pnpm install
pnpm build
pnpm start
```

Then open http://127.0.0.1:7373 in your browser.

For development:

```sh
pnpm install
pnpm dev
```
