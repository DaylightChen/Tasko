# Task 04 — Frontend shell + router + sidebar + Settings

## Goal

Replace the minimal SPA shell from task-01 with the full provider tree, the TanStack Router with all v1 routes (each route a stub view that renders its title — real views land in later tasks), the root layout with a complete sidebar (smart lists + Projects + Tags + bottom links + static footer instead of sync indicator), the New Project modal + inline folder creation, and the Settings view that lets the user pick theme (light / dark / system) and week-start (Sun / Mon) and persists those via `PATCH /api/config`. The typed `apiCall<TOut>` wrapper, the query keys factory, the theme store, the snackbar store + host, and the basic command palette host (a Zustand-open-boolean — full palette content lands in task-18) are all in place. At the end of this task, the app renders, navigates, switches theme, lists projects/folders/tags from the API, and the right-click menus on sidebar items work for rename / delete via the API.

## Steps

1. **Provider tree** — `apps/web/src/main.tsx`:
   ```tsx
   import { StrictMode } from 'react';
   import { createRoot } from 'react-dom/client';
   import { QueryClient, QueryClientProvider } from '@tanstack/react-query';
   import { RouterProvider, createRouter } from '@tanstack/react-router';
   import { ErrorBoundary } from './app/error-boundary';
   import { ThemeBootstrap } from './app/theme-bootstrap';
   import { SnackbarHost } from './components/snackbar/host'; // shipped here as a placeholder; task-05 fills it.
   import { CommandPaletteHost } from './app/command-palette-host'; // skeleton; full content in task-18.
   import { SSEConnector } from './app/sse-connector'; // no-op stub; wired in task-17.
   import { HotkeyProvider } from './app/hotkey-provider'; // no-op stub; wired in task-18.
   import { routeTree } from './routeTree.gen'; // generated by TanStack Router file-based plugin
   import './styles/tokens.css';
   import './styles/base.css';
   import './styles/theme.css';

   const queryClient = new QueryClient({
     defaultOptions: {
       queries: { staleTime: 30_000, gcTime: 5 * 60_000, refetchOnWindowFocus: true, refetchOnReconnect: true, retry: (n) => n < 3 },
       mutations: { retry: 0 },
     },
   });
   const router = createRouter({ routeTree });
   declare module '@tanstack/react-router' { interface Register { router: typeof router } }

   createRoot(document.getElementById('root')!).render(
     <StrictMode>
       <ErrorBoundary>
         <QueryClientProvider client={queryClient}>
           <ThemeBootstrap>
             <HotkeyProvider>
               <SSEConnector />
               <SnackbarHost />
               <CommandPaletteHost />
               <RouterProvider router={router} />
             </HotkeyProvider>
           </ThemeBootstrap>
         </QueryClientProvider>
       </ErrorBoundary>
     </StrictMode>,
   );
   ```

Subscribes to `useConfig()` (task-04 hook below), sets `themeStore.preference` from config on first load, watches `matchMedia('(prefers-color-scheme: dark)')` if preference is 'system', sets `document.documentElement.dataset.theme = resolved`.

   - Add a header `X-Tasko-Tab-Id: <tabId>` on every request — task 17's SSE uses this to discriminate self vs other-tab.
