How to use this preview

  • Open any page directly in a browser — no build step.
  • Use the Theme: ... toggle in the top banner to switch between light, dark, and system preference.
  • Resize the window below 900px to see the layout reflow to mobile (sidebar collapses, bottom nav appears).
  • Hover task rows / kanban cards / sidebar items to see their hover and selected states.
  • Interactivity is deliberately minimal — these are static snapshots of the design, not a working prototype.
